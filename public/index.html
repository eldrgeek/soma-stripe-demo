soma-stripe — one-time donation demo

This page proves the soma-stripe portable component end to end: click Donate, pick an amount, land on Stripe's real hosted Checkout page in test mode, come back here to a thank-you page. Nothing on this page or in its Netlify Function ever touches a live Stripe key — see source.

If the button shows a setup error instead of redirecting to Stripe: this site's STRIPE_SECRET_KEY Netlify env var isn't set yet. That's the one irreducible step reserved for a human — signing up for a Stripe account (even just to get test-mode keys) isn't something an AI does on your behalf. See the repo README for the exact one-command fix.

Portable component: SOMA/standards/soma-stripe/ — copy three files into any SOMA app to add this same donate flow.
